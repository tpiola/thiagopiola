# /public/videos

Coloque o arquivo `hero-loop.mp4` aqui para ativar o vídeo de fundo da seção Hero.

## Especificações recomendadas

- **Formato:** MP4 (H.264) — compatibilidade máxima
- **Resolução:** 1920×1080 mínimo, 2560×1440 ideal
- **Duração:** 10–30 segundos em loop
- **Tamanho:** < 8 MB (usar compressão aggressiva — o vídeo fica sob opacity: 0.25)
- **Conteúdo:** loops abstratos — partículas, formas 3D lentas, fluxos de dados, código minimalista em movimento
- **Sem áudio:** o atributo `muted` já está configurado
